# 週次スライド自動作成ツール

スプレッドシートに数値を入力 → ボタン1つで Google スライドを自動生成します。

---

## 全体フロー

```
【初回のみ】
  1. スクリプトをセットアップ
  2. 「テンプレートを新規作成する」を実行
     → タグ付きテンプレートスライドが自動作成
     → B3 に URL が自動設定される
  （テンプレートのデザインを好みに変更してOK）

【毎週水曜日】
  3. 「入力」シートに数値を入力
  4. 「スライドを作成する」を実行
     → テンプレートがコピーされ、タグが実データに置換される
     → 完成スライドのURLが表示される
```

---

## 初回セットアップ手順

### 1. Google スプレッドシートを新規作成

Google ドライブで「新規 > Google スプレッドシート」を作成します。

### 2. スクリプトエディタを開く

「**拡張機能 > Apps Script**」をクリック。

### 3. コードを貼り付けて保存

1. 左側「コード.gs」をクリック
2. 既存の内容をすべて削除
3. `Code.gs` の内容をコピー＆ペーストして保存（Ctrl+S）

### 4. 初期セットアップを実行

1. スプレッドシートを **F5 でリロード**
2. 上部に「📊 スライド作成」メニューが追加されることを確認
3. 「📊 スライド作成 > ⚙ 初期セットアップ」をクリック
4. 権限承認が出たら「許可」を選択
5. 「入力」シートが作成される

### 5. テンプレートを新規作成する

「📊 スライド作成 > 📋 テンプレートを新規作成する」をクリック

→ 以下が自動で行われます：
- 「水曜定例」形式のテンプレートスライドが Google ドライブに作成される
- テンプレートの URL が「入力」シートの **B3** に自動設定される

> **テンプレートのカスタマイズ**  
> 作成されたテンプレートを開いて、色・フォント・レイアウトを自由に変更できます。  
> `{{タグ}}` の文字列だけは削除しないでください。

## 毎週水曜日の使い方

「入力」シートの **黄色いセル** に数値を入力します。

| 入力欄 | セル | 入力例 |
|--------|------|--------|
| 対象日付 | B2 | `2024/01/10` |
| 前月 在庫進捗率 | B5 | `75.5`（%なし、数値のみ） |
| 前月 残件数 | B6 | `23` |
| 今月 在庫進捗率 | B9 | `45.2` |
| 今月 残件数 | B10 | `87` |
| その他共有事項 | B13 | 自由記述（改行OK） |

**ユニット別データ（Row 19〜28）**

| 列 | 内容 |
|----|------|
| B | 前月 掲出率（数値のみ、例: `80.0`） |
| C | 前月 設定予定件数（例: `5`） |
| D | 前月 アポ未調整件数（例: `3`） |
| F | 今月 掲出率 |
| G | 今月 設定予定件数 |
| H | 今月 アポ未調整件数 |

入力後に「📊 スライド作成 > ▶ スライドを作成する」をクリックすると完成スライドが作成されます。

## テンプレートに使えるタグ一覧

メニュー「📊 スライド作成 > 🏷 使えるタグ一覧を確認する」からいつでも確認できます。

**共通タグ**

| タグ | 置換後の値 |
|------|----------|
| `{{date}}` | 対象日付（例: 2024年01月10日） |
| `{{prev_rate}}` | 前月 在庫進捗率（例: 75.5%） |
| `{{prev_remaining}}` | 前月 残件数（例: 23） |
| `{{curr_rate}}` | 今月 在庫進捗率 |
| `{{curr_remaining}}` | 今月 残件数 |
| `{{other}}` | その他共有事項（全文） |

**ユニット別タグ（n = 1〜10）**

| n | ユニット名 |
|---|---------|
| 1 | 原島ユニット |
| 2 | 山本ユニット |
| 3 | 岡本ユニット |
| 4 | 飯塚ユニット |
| 5 | 岩崎ユニット |
| 6 | 大口ユニット |
| 7 | 中野ユニット |
| 8 | 伊藤ユニット |
| 9 | 佐藤ユニット |
| 10 | 大脇ユニット |

各ユニットのタグ：

| タグ | 内容 |
|------|------|
| `{{un_prev_rate}}` | 前月 掲出率（例: 80.0%） |
| `{{un_prev_sched}}` | 前月 設定予定件数 |
| `{{un_prev_unsched}}` | 前月 アポ未調整件数 |
| `{{un_curr_rate}}` | 今月 掲出率 |
| `{{un_curr_sched}}` | 今月 設定予定件数 |
| `{{un_curr_unsched}}` | 今月 アポ未調整件数 |

## 既存テンプレートをそのまま使う場合

1. 既存のスライドを開き、データを入れたいテキストボックスに上記タグを入力
2. 「入力」シートの **B3** にそのスライドのURLを貼り付ける
3. 「スライドを作成する」を実行

> タグ入力時の注意: 1文字ずつ書式が変わらないように、タグ全体を一度に入力してください。  
> 認識されない場合は一度削除して再入力してみてください。

---

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| メニューが出ない | F5 でリロード |
| 権限エラー | スクリプトエディタで「許可」を再実行 |
| タグが置換されない | タグを削除して再入力（書式分断が原因） |
| 掲出率が `1.0%` になる | `0.75` ではなく `75` と入力 |
| テンプレートのコピー失敗 | テンプレートファイルの権限を「編集者」に変更 |
