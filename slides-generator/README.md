# 週次スライド自動作成ツール

スプレッドシートに数値を入力 → ボタン1つで Google スライドを自動生成します。

---

## 作成されるスライド構成

| スライド | 内容 |
|---------|------|
| 1 | タイトル（水曜定例 + 日付） |
| 2 | 前月 在庫進捗率 + ユニット別一覧表 |
| 3 | 今月 在庫進捗率 + ユニット別一覧表 |
| 4 | その他共有事項 |

---

## 初回セットアップ手順

### 1. Google スプレッドシートを新規作成

1. Google ドライブで「新規 > Google スプレッドシート」を作成
2. シート名は何でも構いません

### 2. スクリプトエディタを開く

1. スプレッドシートの上部メニュー「**拡張機能 > Apps Script**」をクリック
2. 新しいタブでスクリプトエディタが開きます

### 3. コードを貼り付ける

1. エディタ左側の「コード.gs」をクリック
2. 既存の内容（`function myFunction() {...}`）を**すべて削除**
3. `Code.gs` ファイルの内容を**コピー＆ペースト**
4. 左上の「💾 保存」（または Ctrl+S）を押す

### 4. 初期セットアップを実行

1. スプレッドシートに戻る（タブを切り替え）
2. **ページをリロード**（F5 または Ctrl+R）
3. 上部メニューに「📊 スライド作成」が追加されていることを確認
4. 「📊 スライド作成」→「⚙ 初期セットアップ（初回のみ）」をクリック
5. 権限承認ダイアログが出たら「許可」を選択
6. 「✅ セットアップ完了」のメッセージが出れば成功

---

## 毎週水曜日の使い方

### 1. スプレッドシートの「入力」シートを開く

黄色いセルに入力していきます。

| 入力項目 | セル | 入力例 |
|---------|------|--------|
| 対象日付 | B2 | `2024/01/10` |
| 前月 在庫進捗率 | B5 | `75.5`（% を除いた数値） |
| 前月 残件数 | B6 | `23`（件数のみ） |
| 今月 在庫進捗率 | B9 | `45.2` |
| 今月 残件数 | B10 | `87` |
| その他共有事項 | B13 | 自由記述（改行OK） |

**ユニット別データ（Row 19〜28）**

各ユニット行の黄色セルに入力：

| 列 | 内容 |
|----|------|
| B | 前月 掲出率（%、数値のみ: 例 `80.0`） |
| C | 前月 設定予定（件数: 例 `5`） |
| D | 前月 アポ未調整件数（例 `3`） |
| F | 今月 掲出率 |
| G | 今月 設定予定 |
| H | 今月 アポ未調整件数 |

> **注意**: 掲出率は `%` なしの数値で入力してください（例: 75.5%の場合は `75.5`）

### 2. スライドを作成

「📊 スライド作成」→「▶ スライドを作成する」をクリック

→ 完了後に Google スライドの URL が表示されます

---

## ユニット名を変更したい場合

`Code.gs` の以下の部分を編集してください：

```javascript
const CONFIG = {
  UNITS: [
    '原島ユニット', '山本ユニット', '岡本ユニット', '飯塚ユニット', '岩崎ユニット',
    '大口ユニット', '中野ユニット', '伊藤ユニット', '佐藤ユニット', '大脇ユニット'
  ],
```

変更後は「⚙ 初期セットアップ」を再実行してください。

---

## スライドの保存先

作成されたスライドは Google ドライブのマイドライブに  
「`水曜定例_yyyy/MM/dd`」という名前で自動保存されます。

作成履歴は「作成履歴」シートに自動記録されます。

---

## トラブルシューティング

| 症状 | 原因 | 対処 |
|------|------|------|
| メニューに「スライド作成」が出ない | ページ未リロード | F5でリロード |
| 権限エラーが出る | 初回承認が必要 | 「許可」ボタンを押す |
| 「入力」シートが見つからない | セットアップ未実行 | 初期セットアップを実行 |
| 掲出率が`10000%`になる | 小数で入力している | `0.75`ではなく`75`と入力 |
