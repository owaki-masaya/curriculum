# 週次スライド自動作成ツール

スプレッドシートに数値を入力 → ボタン1つで Google スライドを自動生成します。

---

## 動作モード

| 条件 | 動作 |
|------|------|
| テンプレートURLを設定している | テンプレートをコピーし、タグを実データに置換 |
| テンプレートURLが未設定 | デフォルトレイアウトでスライドを新規作成 |

---

## 初回セットアップ手順

### 1. Google スプレッドシートを新規作成

Google ドライブで「新規 > Google スプレッドシート」を作成します。

### 2. スクリプトエディタを開く

スプレッドシートの「**拡張機能 > Apps Script**」をクリック。

### 3. コードを貼り付けて保存

1. 左側の「コード.gs」をクリック
2. 既存の内容をすべて削除
3. `Code.gs` の内容をコピー＆ペーストして保存（Ctrl+S）

### 4. 初期セットアップを実行

1. スプレッドシートを **F5 でリロード**
2. 上部メニューに「📊 スライド作成」が追加されていることを確認
3. 「📊 スライド作成 > ⚙ 初期セットアップ」をクリック
4. 権限承認が出たら「許可」を選択

---

## テンプレートスライドの設定

### テンプレートにタグを入れる

既存のGoogle スライドを開き、データを差し込みたいテキストボックスに下記のタグを入力します。

```
{{date}}           → 例: 2024年01月10日
{{prev_rate}}      → 例: 75.5%
{{prev_remaining}} → 例: 23
{{curr_rate}}      → 例: 45.2%
{{curr_remaining}} → 例: 87
{{other}}          → その他共有事項の全文
```

**ユニット別タグ（u1〜u10）**

| ユニット番号 | ユニット名 |
|------------|---------|
| u1 | 原島ユニット |
| u2 | 山本ユニット |
| u3 | 岡本ユニット |
| u4 | 飯塚ユニット |
| u5 | 岩崎ユニット |
| u6 | 大口ユニット |
| u7 | 中野ユニット |
| u8 | 伊藤ユニット |
| u9 | 佐藤ユニット |
| u10 | 大脇ユニット |

各ユニットに使えるタグ（n = ユニット番号）:

```
{{un_prev_rate}}    → 前月 掲出率（例: 80.0%）
{{un_prev_sched}}   → 前月 設定予定件数（例: 5）
{{un_prev_unsched}} → 前月 アポ未調整件数（例: 3）
{{un_curr_rate}}    → 今月 掲出率
{{un_curr_sched}}   → 今月 設定予定件数
{{un_curr_unsched}} → 今月 アポ未調整件数
```

**使用例（原島ユニットの場合）:**
```
{{u1_prev_rate}} / {{u1_prev_sched}} / {{u1_prev_unsched}}
```

> **注意**: タグは一気に入力してください。途中で文字スタイルが変わると  
> GAS が認識できない場合があります（例: 太字＋通常が混在）。

### テンプレートURLをスプレッドシートに設定

「入力」シートの **B3（テンプレートURL/ID）** に、  
テンプレートスライドのURL（または ID のみ）を貼り付けます。

```
例: https://docs.google.com/presentation/d/XXXXXXXXXXXXXXXX/edit
```

## 毎週水曜日の使い方

1. 「入力」シートの黄色いセルに数値を入力

| 入力項目 | セル | 例 |
|---------|------|---|
| 対象日付 | B2 | `2024/01/10` |
| 前月 在庫進捗率 | B5 | `75.5`（%なし） |
| 前月 残件数 | B6 | `23` |
| 今月 在庫進捗率 | B9 | `45.2` |
| 今月 残件数 | B10 | `87` |
| その他共有事項 | B13 | 自由記述（改行OK） |

**ユニット別データ（Row 19〜28）**

| 列 | 内容 |
|----|------|
| B | 前月 掲出率（%なし数値: `80.0`） |
| C | 前月 設定予定件数（`5`） |
| D | 前月 アポ未調整件数（`3`） |
| F | 今月 掲出率 |
| G | 今月 設定予定件数 |
| H | 今月 アポ未調整件数 |

2. 「📊 スライド作成 > ▶ スライドを作成する」をクリック
3. 完了ポップアップに表示された URL を開く

---

## タグ一覧の確認

メニュー「📊 スライド作成 > 🏷 使えるタグ一覧を確認する」から、  
いつでもタグ一覧をポップアップで確認できます。

---

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| メニューが出ない | F5 でページをリロード |
| 権限エラー | スクリプトエディタで「許可」を再実行 |
| タグが置換されない | タグ文字列が分断されていないか確認（一度削除して再入力） |
| 掲出率が`1.0%`になる | `0.75`ではなく`75`と入力してください |
| テンプレートのコピーに失敗 | テンプレートファイルの共有設定で「編集者」権限があるか確認 |
